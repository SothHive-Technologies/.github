# Code of Conduct

SothHive Technologies is a studio. We work in public enough that the same standards apply in GitHub issues, pull requests, discussions, and reviews.

## Expected

- Be precise. Disagree with the idea, not the person.
- Assume good faith, then ask a clarifying question.
- Protect customer data. Never paste secrets, production dumps, or client identifiers into public issues.
- Credit the work. Name the person who unblocked you.

## Not tolerated

- Harassment, discrimination, or sexualized language.
- Personal attacks, doxxing, or publishing private communication.
- Spam, phishing, or using this org to sell unrelated services.

## Enforcement

Report incidents to [info@softhive.com](mailto:info@softhive.com). Maintainers may warn, restrict, or remove access. We will not debate the report in a public thread.

This policy is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
